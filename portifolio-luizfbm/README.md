# Portifolio Luiz FBM

Site estático de prospecção para pequenos negócios locais, com foco em clínicas, consultórios, laboratórios e serviços de saúde que precisam de uma presença própria além do Instagram.

## Como abrir

Abra `index.html` no navegador ou rode um servidor local:

```bash
python3 -m http.server 4173
```

Depois acesse:

```text
http://localhost:4173/
```
