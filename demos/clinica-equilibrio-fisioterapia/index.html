Dúvidas comuns

Respostas curtas antes do primeiro contato.

Esta página é oficial da clínica?

Não. Este é um conceito visual criado com informações públicas para demonstrar como uma página própria poderia organizar o contato.

O atendimento é pelo WhatsApp?

O número público encontrado abre uma conversa pelo WhatsApp. O canal definitivo deve ser confirmado pela clínica.

Por que não há endereço completo?

As fontes públicas consultadas mostram dados diferentes. O correto é confirmar o endereço com a clínica antes de publicar oficialmente.
