# Scripts de WhatsApp

Use estes scripts como ponto de partida. Antes de enviar, ajuste o nome, o nicho e o problema real que você viu no perfil.

Regra: não mande tudo de uma vez. O primeiro objetivo é conseguir permissão para enviar 3 sugestões.

Regra do diagnóstico: as 3 sugestões devem vender o problema, não listar o pacote. Mostre o atrito que a pessoa pode ter antes de chamar no WhatsApp, conecte com uma página simples e peça permissão para mostrar visualmente.

Regra de qualificação: depois do exemplo, não jogue as duas ofertas como cardápio. Faça uma pergunta simples, entenda se a pessoa quer um link organizado ou uma presença oficial e recomende uma opção principal.

## Primeiro contato por WhatsApp

```text
Oi, [nome], tudo bem? Sou Luiz, trabalho com presença digital para negócios locais aqui no ES.

Vi o perfil de vocês no Google/Instagram e notei alguns pontos simples que podem facilitar o contato pelo WhatsApp.

Posso te mandar 3 sugestões rápidas?
```

## Primeiro contato por Instagram

```text
Oi, [nome], tudo bem? Vi o perfil de vocês e percebi alguns ajustes simples que podem deixar o caminho até o WhatsApp mais claro.

Posso te mandar 3 sugestões rápidas?
```

## Primeiro contato para profissional dono-operador

Use quando o perfil parece ser de uma pessoa que atende e decide, como fisioterapeuta, esteticista, nutricionista, psicóloga, podóloga, massoterapeuta, personal trainer ou dono de microestúdio.

```text
Oi, [nome], tudo bem? Sou Luiz, trabalho com presença digital para profissionais e negócios locais aqui em Vitória.

Vi seu perfil e percebi que o Instagram já mostra bem seu trabalho, mas alguns pontos poderiam deixar o caminho até o WhatsApp mais claro para quem chega pela primeira vez.

Posso te mandar 3 sugestões rápidas?
```

## Se responder "pode"

Use quando o lead acabou de permitir as sugestões. O objetivo é mostrar que você entendeu o problema e deixar a página simples como consequência natural, sem parecer proposta formal.

```text
Boa, [nome]. Obrigado.

Olhando rápido, eu não mexeria no que já está funcionando no Instagram. O ponto é mais o caminho de quem chega pela primeira vez.

Hoje a pessoa precisa entender em poucos segundos:

1. quais atendimentos você oferece
2. onde atende ou qual região cobre
3. como chamar no WhatsApp já dizendo o que procura

Isso normalmente fica mais claro em uma página curta de apresentação, usando o que você já tem no perfil.

Quer que eu te mande um exemplo visual simples para ficar mais fácil de imaginar?
```

## Se respondeu "pode", recebeu diagnóstico e não respondeu

Use depois de algumas horas ou no dia seguinte. Não cobre resposta. Reposicione o convite e deixe claro que ainda não é proposta fechada.

```text
Oi, [nome]. Passando só para complementar: talvez por texto tenha ficado meio abstrato.

A ideia é uma página curta, com seus atendimentos, região e botão direto para WhatsApp, sem mexer no que já funciona no Instagram.

Se quiser, te mando um exemplo visual simples e você vê se faz sentido.
```

## Se o WhatsApp Business responder automaticamente

Use quando você manda a primeira mensagem e recebe um menu automático, como "1. Conhecer horários", "2. Fazer aula experimental", "3. Saber valores".

```text
Obrigado, [nome]. Só para explicar melhor: não estou buscando atendimento.

Sou Luiz, trabalho com presença digital para negócios locais aqui em Vitória. Vi que o WhatsApp de vocês já está bem organizado. Minha sugestão é mais sobre o caminho antes dele: Instagram/Google, uma página simples e depois o WhatsApp.

Posso te mandar 3 sugestões rápidas?
```

## Se o cliente já usa WhatsApp Business bem

```text
Vi que vocês já usam o WhatsApp de forma organizada, com mensagem inicial e opções de atendimento.

O ponto que eu olharia é antes da pessoa chegar no WhatsApp: como ela entende os serviços, a localização e os próximos passos quando vem pelo Instagram ou pelo Google.

Posso te mandar 3 sugestões rápidas sobre isso?
```

## Envio de exemplo

```text
Perfeito. Este é um exemplo do tipo de página que eu monto:

[link]

A ideia é simples: deixar claro o que vocês fazem, onde atendem e qual é o caminho mais fácil para chamar no WhatsApp.
```

## Qualificação depois do exemplo

Use depois que a pessoa recebeu o exemplo e parece aberta. O objetivo é entender qual papel a Presença Local em 72h precisa cumprir para o lead.

```text
Pensando no que faria mais sentido para você: a ideia é ter um link mais simples e organizado para colocar no Instagram, ou você quer algo com mais cara de site oficial mesmo?
```

## Se o lead indicar algo simples

Use quando a pessoa falar "algo simples", "só para colocar no Instagram", "só organizar", "por enquanto algo básico" ou parecer sensível a preço.

```text
Pelo que vi, eu faria isso dentro da Presença Local em 72h.

Uma página clara com sua apresentação, serviços principais, região de atendimento e botão direto para WhatsApp já resolveria bem esse primeiro passo sem virar um projeto grande demais.
```

## Se o lead indicar objetivo simples depois do preço

Use quando a pessoa pediu preço/custo/valor, recebeu a pergunta de qualificação e respondeu que quer organizar o caminho.

Não responder só "entendi, faz sentido" ou "dá para seguir por essa linha". Essa resposta é neutra demais e não avança.

```text
Entendi. Para organizar esse caminho, eu faria dentro da Presença Local em 72h mesmo.

A entrega ficaria bem objetiva: apresentação do trabalho, tratamentos principais, região de atendimento e botão direto para WhatsApp, sem transformar isso em um site grande.

Daí o próximo passo é fechar o escopo certinho e te passar a condição para começar.
```

## Se o lead indicar site oficial

Use quando a pessoa falar "site", "algo mais profissional", "domínio", "Google", "divulgar melhor", "colocar fotos", "mais informações" ou "presença oficial".

```text
Pelo que você me falou, faz sentido tratar isso como Presença Local em 72h.

A ideia é montar uma página com cara de apresentação oficial: textos, serviços, localização ou região, WhatsApp e estrutura simples para divulgar melhor.
```

## Se ainda estiver em dúvida entre as duas

Use quando a pessoa não souber responder ou parecer indecisa.

```text
Sem problema. Pelo que vi no seu perfil, eu indicaria Presença Local em 72h.

Ela organiza o principal: apresentação, serviços, região e WhatsApp. O escopo exato a gente ajusta para caber no que precisa aparecer agora.
```

## Se o lead perguntar o preço direto

```text
Depende um pouco do que precisa aparecer na página e do objetivo principal.

Para eu te direcionar melhor: você quer usar essa página mais como apresentação oficial do trabalho, ou mais para organizar o caminho de quem vem do Instagram, Google ou WhatsApp?
```

## Se achar caro

```text
Entendo. Nesse caso, dá para simplificar o que entra na primeira entrega.

Eu manteria a Presença Local em 72h, focando no que realmente precisa aparecer agora: apresentação, serviços principais, região e botão direto para WhatsApp.

Depois, se fizer sentido, dá para evoluir com mais informações e ajustes.
```

## Alternativa com entrada

```text
Também posso dividir em duas partes: 50% para começar e 50% na entrega.

Assim eu reservo a produção e vocês pagam o restante quando estiver pronto.
```

## Fechamento

```text
Fechado. Para começar, vou precisar destas informações:

- nome correto do negócio
- serviços principais
- WhatsApp de atendimento
- endereço ou região atendida
- Instagram
- fotos autorizadas, se tiver

Para reservar a entrega, trabalho com 50% de entrada e 50% na entrega.
```
